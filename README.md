A standalone, GitHub-compatible git forge: git smart HTTP (upload-pack v2, receive-pack v0), the
REST v3 API for repositories, branches, commits, contents, labels, issues and pull requests, the
GraphQL v4 API, and a Model Context Protocol endpoint — one Node 22 process, standard library
only, everything served from its own in-memory store. 120/120 conformance checks, 981/1000 local
score on the bounty's suite.

## Run it

```sh
node --experimental-strip-types main.ts
```
